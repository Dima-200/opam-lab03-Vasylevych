# Лабораторна робота №3 — Рекурсивні алгоритми

**Дисципліна:** Основи програмування та алгоритмічні мови  
**Група:** КН-3/1  
**Мова:** C#  
**Варіант:** N = 3, K = 6, a = 0, b = 3, c = 3

## Мета роботи

Навчитися створювати рекурсивні алгоритми, працювати з вкладеними каталогами, знаходити максимум масиву поділом навпіл, перебирати всі шляхи та досліджувати стек викликів.

## Завдання 1. Обхід каталогів

Програма рекурсивно обходить задану папку та вкладені каталоги, підраховує файли з розширенням `.cs` і сумує їхній розмір у байтах.

**Базовий випадок:** якщо каталог не має вкладених папок, рекурсивні виклики не виконуються, а функція повертає результат для поточного каталогу.

## Завдання 2. Пошук максимуму

Створюється масив із 16 випадкових чисел у діапазоні від -20 до 20 за допомогою `new Random(3)`. Масив ділиться на дві половини, після чого знаходиться більший із двох максимумів.

**Базовий випадок:** якщо `lo == hi`, функція повертає єдиний елемент `a[lo]`.

Глибина рекурсії становить 5 рівнів, якщо рахувати початковий виклик. `log₂16 = 4` — кількість поділів до одного елемента.

## Завдання 3. Перебір шляхів

Потрібно знайти всі шляхи в матриці 3 × 3 від верхнього лівого кута до нижнього правого, рухаючись лише вправо (`R`) та вниз (`D`).

**Базовий випадок:** якщо досягнуто нижнього правого кута, шлях додається до результатів.

Кількість шляхів: 6.

## Завдання 4. Трасування рекурсії

Для масиву `[7, -2, 15, 4]` функція `TraceMax` виводить входи та виходи рекурсивних викликів із відступами.

**Трасування:** вставити фактичний вивід програми з консолі.

Рядки `exit` з'являються у зворотному порядку, оскільки батьківська функція завершується після завершення дочірніх викликів і отримання їхніх результатів.

## Завдання 5. Ітеративна версія

Функція `MaxIterative` знаходить максимум циклом.

**Порівняння:** циклічний варіант простіший для пошуку максимуму, оскільки послідовно перевіряє елементи й зберігає поточний максимум. Рекурсивний варіант наочно демонструє поділ задачі навпіл.

Для обходу каталогів ітеративним способом потрібен додатковий стек або черга шляхів до каталогів, які ще потрібно обробити. Цикл самостійно не зберігає всі вкладені каталоги для подальшого обходу.

## Висновок

Під час роботи реалізовано рекурсивний обхід каталогів, пошук максимуму поділом навпіл і перебір шляхів у матриці. Досліджено порядок викликів і повернення рекурсивних функцій та порівняно рекурсивний пошук максимуму з циклічним.
